---

## 期货分钟行情

接口路径：`futures/kline-minute`
请求方式：**`POST`**
tool_id：`list_futures_kline_minute`

接口说明：通过必填的合约代码，以及可选的K线周期、交易日期范围（格式yyyy-MM-dd）、页码、页大小等参数，查询期货的分钟级K线行情数据，返回交易日期、合约代码、K线开始时间（yyyy-MM-dd HH:mm:ss）、K线周期、开盘价、最高价、最低价、收盘价、成交量、成交金额、持仓量等核心数据，可用于期货行情分析、历史走势回溯等场景。（目前只有富时A50期货股指）

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `futureCode` | — | string | 合约代码 | `CHINA50` |
| `klinePeriod` | — | integer | K线周期 | `-2` |
| `beginDate` | — | string | 交易日期起始值，格式yyyy-MM-dd | `2026-07-23` |
| `endDate` | — | string | 交易日期结束值，格式yyyy-MM-dd | `2026-07-23` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `tradeDate` | 交易日期，交易所业务交易日 | `2026-07-23 00:00:00` |
| `futureCode` | 合约代码 | `IF2508` |
| `klineStartTime` | K线开始时间，真实自然时间 | `2026-07-23 09:30:00` |
| `klinePeriod` | K线周期 | `1` |
| `openPrice` | 开盘价 | `3800.12` |
| `highPrice` | 最高价 | `3815.34` |
| `lowPrice` | 最低价 | `3792.56` |
| `closePrice` | 收盘价 | `3808.78` |
| `volumeLot` | 成交量 | `12500` |
| `amount` | 成交金额 | `485000000` |
| `openInterest` | 持仓量 | `86000` |
| `futureName` | 合约名称 | `富时A50期货股指` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Body JSON 可选参数: futureCode, klinePeriod, beginDate, endDate, pageNum, pageSize
investoday-api futures/kline-minute --method POST --body-json '{"futureCode":"CHINA50","klinePeriod":-2,"beginDate":"2026-07-23"}'
```
