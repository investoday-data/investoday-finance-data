## 期货分钟行情

接口路径：`futures/kline-minute`
请求方式：**`POST`**
tool_id：`list_futures_kline_minute`

接口说明：通过必填的合约代码，以及可选的K线周期、交易日期范围（格式yyyy-MM-dd）、页码、页大小等参数，查询期货的分钟级K线行情数据，返回交易日期、合约代码、K线开始时间（yyyy-MM-dd HH:mm:ss）、K线周期、开盘价、最高价、最低价、收盘价、成交量、成交金额、持仓量等核心数据，可用于期货行情分析、历史走势回溯等场景。（目前只有富时A50期货股指）

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `futureCode` | — | string | 合约代码 | `CHINA50` |
| `klinePeriod` | — | integer | K线周期 | `-2` |
| `beginDate` | — | string | 交易日期起始值，格式yyyy-MM-dd | `2026-07-23` |
| `endDate` | — | string | 交易日期结束值，格式yyyy-MM-dd | `2026-07-23` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `tradeDate` | 交易日期，交易所业务交易日 | `2026-07-23 00:00:00` |
| `futureCode` | 合约代码 | `IF2508` |
| `klineStartTime` | K线开始时间，真实自然时间 | `2026-07-23 09:30:00` |
| `klinePeriod` | K线周期 | `1` |
| `openPrice` | 开盘价 | `3800.12` |
| `highPrice` | 最高价 | `3815.34` |
| `lowPrice` | 最低价 | `3792.56` |
| `closePrice` | 收盘价 | `3808.78` |
| `volumeLot` | 成交量 | `12500` |
| `amount` | 成交金额 | `485000000` |
| `openInterest` | 持仓量 | `86000` |
| `futureName` | 合约名称 | `富时A50期货股指` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Body JSON 可选参数: futureCode, klinePeriod, beginDate, endDate, pageNum, pageSize
investoday-api futures/kline-minute --method POST --body-json '{"futureCode":"CHINA50","klinePeriod":-2,"beginDate":"2026-07-23"}'
```

## 上期所金属库存日报

接口路径：`futures/shfe-metal-d`
请求方式：**`POST`**
tool_id：`list_futures_shfe_metal_d`

接口说明：支持通过期货品种代码及日期范围查询上期所金属类期货的每日库存日报数据，返回包含报告类型、交易日期、交易所代码、期货代码与名称、地区、仓单数量及增减量等核心指标，便于进行库存趋势分析与市场监测。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `futureCode` | — | string | 期货品种代码；不传返回全部品种 | `CU` |
| `beginDate` | — | string | 报告日期起始值，格式yyyy-MM-dd | `2024-01-01` |
| `endDate` | — | string | 报告日期结束值，格式yyyy-MM-dd | `2026-09-27` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `reportType` | 日报明细或日报汇总 | `dailyDetail` |
| `tradeDate` | 报告日期 | `2026-09-22 00:00:00` |
| `exchangeCode` | 交易所代码 | `SHFE` |
| `futureCode` | 期货品种代码 | `ZN` |
| `regionName` | 地区名称 | `浙江` |
| `statType` | 汇总类型 | — |
| `futureName` | 品种名称 | `锌` |
| `warehouseReceiptQuantity` | 仓单数量 | `9786` |
| `warehouseReceiptChange` | 仓单增减数量 | `0` |
| `measureUnit` | 计量单位 | `吨` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Body JSON 可选参数: futureCode, beginDate, endDate, pageNum, pageSize
investoday-api futures/shfe-metal-d --method POST --body-json '{"futureCode":"CU","beginDate":"2024-01-01","endDate":"2026-09-27"}'
```

## 上期所金属库存周报

接口路径：`futures/shfe-metal-w`
请求方式：**`POST`**
tool_id：`list_futures_shfe_metal_w`

接口说明：支持通过单个或批量期货合约代码及日期范围查询上期所金属类期货的周度库存周报，返回包含报告类型、交易日期、交易所代码、地区名称、期货品种信息、上周与本期的库存数量、仓单数量、库存增减量、可用库容量及其变化量等核心指标，便于分析金属期货的供需动态与库存趋势。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `futureCode` | — | string | 单个期货合约或品种代码；与futureCodes二选一【与futureCodes组成多选一参数，必须且只能传递其中一个】 | `CU` |
| `futureCodes` | — | array | 多个期货合约或品种代码；与futureCode二选一【与futureCode组成多选一参数，必须且只能传递其中一个】 | `['CU', 'ZN']` |
| `beginDate` | — | string | 报告日期起始值，格式yyyy-MM-dd | `2024-01-01` |
| `endDate` | — | string | 报告日期结束值，格式yyyy-MM-dd | `2026-09-27` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `reportType` | 周报明细或周报汇总 | `weeklyDetail` |
| `tradeDate` | 报告日期 | `2026-09-04 00:00:00` |
| `futureCode` | 期货品种代码 | `BC` |
| `exchangeCode` | 交易所代码 | `INE` |
| `statType` | 汇总类型 | — |
| `regionName` | 地区名称 | `广东` |
| `futureName` | 期货品种名称 | `铜(BC)` |
| `inventoryLwk` | 上周库存数量 | `350` |
| `warehouseReceiptLwk` | 上周仓单数量 | `350` |
| `inventoryCwk` | 本周库存数量 | `325` |
| `warehouseReceiptCwk` | 本周仓单数量 | `325` |
| `inventoryChange` | 库存增减数量 | `-25` |
| `warehouseReceiptChange` | 仓单增减数量 | `-25` |
| `capacityLwk` | 上周可用库容量 | `9650` |
| `capacityCwk` | 本周可用库容量 | `9675` |
| `capacityChange` | 可用库容量增减 | `25` |
| `measureUnit` | 计量单位 | `吨` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Body JSON 可选参数: futureCode, futureCodes, beginDate, endDate, pageNum, pageSize
investoday-api futures/shfe-metal-w --method POST --body-json '{"futureCode":"CU","futureCodes":["CU","ZN"],"beginDate":"2024-01-01"}'
```

## LME金属库存

接口路径：`futures/lme-metal`
请求方式：**`POST`**
tool_id：`list_futures_lme_meta`

接口说明：支持通过单个或批量LME期货产品代码及日期范围查询指定仓库地点的库存变动详情，返回交易日期、国家地区、期初/期末库存、入库/出库量及有效与注销仓单数量等核心指标，便于分析全球金属库存动态。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `futureCode` | — | string | 单个LME产品或品种代码；与futureCodes二选一【与futureCodes组成多选一参数，必须且只能传递其中一个】 | `Aluminium Alloy Ingots 226` |
| `futureCodes` | — | array | 多个LME产品或品种代码；与futureCode二选一【与futureCode组成多选一参数，必须且只能传递其中一个】 | `['Aluminium Alloy Ingots 226', 'Aluminium Alloy Ingots A380.1']` |
| `beginDate` | — | string | 库存日期起始值，格式yyyy-MM-dd | `2024-01-01` |
| `endDate` | — | string | 库存日期结束值，格式yyyy-MM-dd | `2026-09-27` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `tradeDate` | 库存日期 | `2026-09-22 00:00:00` |
| `futureCode` | LME产品或品种代码 | `Aluminium Alloy Ingots 226` |
| `countryRegion` | 国家或地区 | `Belgium` |
| `warehouseLocation` | 仓库地点 | `Antwerp` |
| `inventoryOpen` | 期初库存 | `300` |
| `inboundQuantity` | 入库量 | `0` |
| `outboundQuantity` | 出库量 | `0` |
| `inventoryClose` | 期末库存总量 | `300` |
| `validWarehouseReceipt` | 可用吨数 | `300` |
| `cancelledWarehouseReceipt` | 已注销吨数 | `0` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Body JSON 可选参数: futureCode, futureCodes, beginDate, endDate, pageNum, pageSize
investoday-api futures/lme-metal --method POST --body-json '{"futureCode":"Aluminium Alloy Ingots 226","futureCodes":["Aluminium Alloy Ingots 226","Aluminium Alloy Ingots A380.1"],"beginDate":"2024-01-01"}'
```
