## 全球权益市场估值指标

接口路径：`macro/equity-valuations`
请求方式：**`POST`**
tool_id：`list_macro_equity_val`

接口说明：支持通过指定市场名称、时间范围（开始日期格式为yyyy-MM-dd，结束日期格式为yyyy-MM-dd），并可配合页码、页大小进行分页，查询全球权益市场的估值指标数据，返回截止日期（格式为yyyy-MM-dd HH:mm:ss）、市场名称、指数代码、指数名称、市盈率TTM估值倍数、每股收益TTM指标、预期市盈率估值倍数等核心信息，可用于全球各权益市场的估值分析、指数估值对比等投研场景。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `marketName` | — | string | 市场名称，传入时优先于marketNames | `United States` |
| `beginDate` | — | string | 开始截至日期，格式yyyy-MM-dd | `2024-01-01` |
| `endDate` | — | string | 结束截至日期，格式yyyy-MM-dd | `2026-08-14` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `endDate` | 截至日期 | `2026-06-30 00:00:00` |
| `marketName` | 市场名称 | `United States` |
| `indexCode` | 代表指数代码 | `SPX` |
| `indexName` | 指数名称 | `S&P 500` |
| `peTtm` | 市盈率TTM估值倍数 | `24.75` |
| `epsTtm` | 每股收益TTM指数 | `112.35` |
| `peForward` | 预期市盈率估值倍数 | `21.63` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Body JSON 可选参数: marketName, beginDate, endDate, pageNum, pageSize
investoday-api macro/equity-valuations --method POST --body-json '{"marketName":"United States","beginDate":"2024-01-01","endDate":"2026-08-14"}'
```
