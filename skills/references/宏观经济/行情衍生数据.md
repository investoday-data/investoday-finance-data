## 场内基金资金流向

接口路径：`fund/flow`
请求方式：**`POST`**
tool_id：`list_fund_flow`

接口说明：支持通过单个基金代码、多个基金代码列表，结合指定的日期范围（开始日期、结束日期格式均为yyyy-MM-dd），分页查询场内ETF基金的资金流向数据，返回基金基本信息（代码、内部编码、名称）、发布日期、内外盘总量及差值、平均价格，以及主力、超大单、大单、中单、小单各量级的流入流出金额，还有总流入流出、净流入金额、控盘比例等核心指标，可用于场内ETF的资金动向分析、投研决策等场景。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `fundCode` | — | string | 基金代码【与fundCodes组成多选一参数，必须且只能传递其中一个】 | `510300` |
| `fundCodes` | — | array | 基金代码列表【与fundCode组成多选一参数，必须且只能传递其中一个】 | `['510300', '159915']` |
| `beginDate` | — | string | 开始日期，格式yyyy-MM-dd | `2025-01-01` |
| `endDate` | — | string | 结束日期，格式yyyy-MM-dd，包含当天 | `2025-12-31` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 接口示例

```bash
# Body JSON 可选参数: fundCode, fundCodes, beginDate, endDate, pageNum, pageSize
investoday-api fund/flow --method POST --body-json '{"fundCode":"510300","fundCodes":["510300","159915"],"beginDate":"2025-01-01"}'
```
