# 基金 / 基金资料

---

## 基金融资融券交易明细

接口路径：`fund/margin-trade`
请求方式：**`POST`**
tool_id：`list_fund_margin_trade`

接口说明：支持通过单个基金代码或批量基金代码，结合指定的日期范围（日期格式为yyyy-MM-dd），并可通过页码、页长控制分页，查询基金的融资融券交易明细数据，包括交易日期、基金代码及名称、融资余额、融资买入额、融资偿还额、融券余量、融券卖出量、融券余量金额、融资融券余额等核心指标，可用于分析基金的杠杆交易情况及资金动向。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `fundCode` | — | string | 股票代码【与fundCodes组成多选一参数，必须且只能传递其中一个】 | `002594` |
| `fundCodes` | — | array | 股票代码列表【与fundCode组成多选一参数，必须且只能传递其中一个】 | `['000001', '600519']` |
| `beginDate` | — | string | 开始日期 | `2025-01-01` |
| `endDate` | — | string | 结束日期 | `2025-01-01` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `date` | 交易日期 | `2023-10-26` |
| `fundCode` | 基金代码 | `600519` |
| `fundName` | 基金名称 | `贵州茅台` |
| `marginBalance` | 融资余额（元） | `123456789.12` |
| `marginBuyAmount` | 融资买入额（元） | `123456789.12` |
| `marginRepayAmount` | 融资偿还额（元） | `-1254300.75` |
| `shortBalanceVolume` | 融券余量（股） | `123456.78` |
| `shortSellVolume` | 融券卖出量（股） | `12345.67` |
| `shortBalanceAmount` | 融券余量金额（元） | `123456789.12` |
| `marginShortBalance` | 融资融券余额（元） | `1234567890.12` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Body JSON 可选参数: fundCode, fundCodes, beginDate, endDate, pageNum, pageSize
investoday-api fund/margin-trade --method POST --body-json '{"fundCode":"002594","fundCodes":["000001","600519"],"beginDate":"2025-01-01"}'
```
