# 基金 / 基金行情 / 实时行情

---

## ETF最新实时日行情

接口路径：`fund-quote/realtime`
请求方式：`GET`
tool_id：`get_fund_quote_realtime`

接口说明：通过基金代码获取ETF基金的最新实时行情数据，包括基金代码、名称、市场类型、开盘价、昨日收盘价、当前价格、涨跌幅、最高价、最低价、数据时间和系统时间等核心数据，适用于实时监控ETF基金的市场表现和价格变动。

### 输入参数

**Query 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `fundCode` | ✅ | string | 基金代码 | `159001` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `fundCode` | 基金代码 | `159616` |
| `fundName` | 基金名称 | `农牧ETF` |
| `marketType` | 市场类型(沪-sh、深-sz、京-bj) | `sz` |
| `openPrice` | 开盘价 | `0.855` |
| `closePriceYDay` | 昨日收盘价 | `0.855` |
| `currentPrice` | 当前价格 | `0.84` |
| `changeRatio` | 涨跌幅 | `-0.0175` |
| `highPrice` | 最高价 | `0.855` |
| `lowPrice` | 最低价 | `0.835` |
| `dataTime` | 数据时间 | `2025-11-04 15:09:00` |
| `sysTime` | 系统时间 | `2025-11-04 15:09:02` |
| `status` | 状态 | `0` |

### 接口示例

```bash
investoday-api fund-quote/realtime fundCode=159001
```

## ETF核心实时行情

接口路径：`fund-quote/core`
请求方式：**`POST`**
tool_id：`get_fund_quote_core`

接口说明：使用ETF代码列表（可批量传入），并指定资产类型为etf，即可获取对应ETF的核心实时行情数据，涵盖证券基本信息（代码、名称、交易所）、关键价格指标（最新价、昨收价、开盘价、最高价、最低价等）、涨跌数据（涨跌额、涨跌幅、振幅等）、成交数据（成交量、成交额、成交均价等）、买卖盘深度（买一到买二、卖一到卖二的报价及量）、ETF专属指标（IOPV、净值、折溢价率等）以及交易日期、行情快照时间等时间信息，适用于ETF实时行情监测、交易决策分析等场景。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `codes` | ✅ | array | 股票代码 | `['159001', '510300']` |
| `assetType` | ✅ | string | 资产类型（固定为 etf） | `etf` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `data` | 业务数据 | `{}` |

### 接口示例

```bash
investoday-api fund-quote/core --method POST --body-json '{"codes":["159001","510300"],"assetType":"etf"}'
```
