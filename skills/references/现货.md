# 现货

---

## 现货每日行情

接口路径：`macro/spot-quotes`
请求方式：**`POST`**
tool_id：`list_macro_spot_quotes`

接口说明：支持通过现货品种代码、交易日期范围（格式为yyyy-MM-dd）进行筛选，并可设置页码和页长实现分页查询，获取现货每日行情数据，返回交易日期、现货品种代码、现货类型、交易所代码、货币代码、昨收盘价、开盘价、最高价、最低价、最新价、成交量、成交金额等核心指标，可用于现货市场行情监测、价格走势分析、交易决策参考等场景。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `spotCode` | — | string | 现货品种代码 | `SPOT001` |
| `beginDate` | — | string | 开始交易日期，格式yyyy-MM-dd | `2026-01-01` |
| `endDate` | — | string | 结束交易日期，格式yyyy-MM-dd | `2026-08-14` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `tradeDate` | 交易日期 | `2026-08-14 00:00:00` |
| `spotCode` | 现货品种代码 | `SPOT001` |
| `currencyCode` | 货币代码 | `USD` |
| `prevClose` | 昨收盘价 | `100.25` |
| `openPrice` | 开盘价 | `101` |
| `highPrice` | 最高价 | `103.5` |
| `lowPrice` | 最低价 | `99.75` |
| `lastPrice` | 最新价 | `102.88` |
| `volume` | 成交量 | `1234567` |
| `amount` | 成交金额 | `987654321.25` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Body JSON 可选参数: spotCode, beginDate, endDate, pageNum, pageSize
investoday-api macro/spot-quotes --method POST --body-json '{"spotCode":"SPOT001","beginDate":"2026-01-01","endDate":"2026-08-14"}'
```
