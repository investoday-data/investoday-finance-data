## 指数行情技术指标

接口路径：`index/technical-indicators`
请求方式：`GET`
tool_id：`list_index_technical_indicators`

接口说明：通过指数代码获取指定指数的技术指标数据，包括最新趋势、52周最高/最低点、不同时间维度的涨跌幅、市场热度、主力资金流向、夏普比率、年化波动率及收益率等核心指标，适用于市场分析和投资决策。

### 输入参数

**Query 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `indexCode` | ✅ | string | 指数代码 | `000001` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `date` | 发布日期 | `2025-09-18` |
| `indexCode` | 指数代码 | `000001` |
| `indexName` | 指数名称 | `上证指数` |
| `latestTrend` | 最新趋势 | `上涨` |
| `high52Week` | 52周最高 | `3500.25` |
| `low52Week` | 52周最低 | `2800.15` |
| `weeklyReturn` | 一周涨跌幅(%) | `0.3974` |
| `oneMRETURNPct` | 一月涨跌幅(%) | `-0.3734` |
| `threeMonthReturn` | 三月涨跌幅(%) | `2.5926` |
| `halfYearReturn` | 半年涨跌幅(%) | `-3.2036` |
| `oneYearReturn` | 一年涨跌幅(%) | `5.5032` |
| `marketWeather` | 市场天气 | `晴` |
| `oneDayReturn` | 一日涨跌幅(%) | `0.8685` |
| `peUndervaluedCriticalValue` | PE低估临界值 | `10` |
| `peHighOvervaluedCriticalValue` | PE高估临界值 | `30` |
| `pbLowCriticalValue` | PB低估临界值 | `1` |
| `pbHighOvervaluedThreshold` | PB高估临界值 | `3.0` |
| `peValuationPercentile` | PE估值百分位 | `80` |
| `pbValuationPercentile` | PB估值百分位 | `65` |
| `applicableValuationIndex` | 适用估值指标（只适用ETF基准指数） | `1` |
| `marketHeat` | 市场热度 | `0.72` |
| `return3Y` | 三年涨跌幅(%) | `29.2451` |
| `ytdReturn` | 今年以来涨跌幅(%) | `6.233` |
| `last20DaysMainInflowPer10KUnits` | 近20日主力流入(万元) | `52000` |
| `last20DaysMainOutflowPer10KUnits` | 近20日主力流出(万元) | `48000` |
| `last20DaysMainNetFlowPer10KUnits` | 近20日主力净流(万元) | `4000` |
| `last10DaysMainInflowPer10KUnits` | 近10日主力流入(万元) | `31000` |
| `last10DaysMainOutflowPer10KUnits` | 近10日主力流出(万元) | `29500` |
| `latest10DaysMainNetFlowPer10KUnits` | 近10日主力净流(万元) | `1500.0` |
| `last5DaysMainInflowPer10KUnits` | 近5日主力流入(万元) | `18000` |

### 接口示例

```bash
investoday-api index/technical-indicators indexCode=000001
```

## 指数估值信息

接口路径：`index/valuation`
请求方式：`GET`
tool_id：`get_index_valuation`

接口说明：通过指数代码和时间范围查询指数的估值信息，包括指数名称、发布机构、市场类型、行情时间、总市值、市盈率、市净率、换手率和股息率等核心数据，适用于金融分析和市场研究。

### 输入参数

**Query 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `indexCode` | ✅ | string |  | `399300` |
| `beginDate` | — | string |  | `2025-11-04` |
| `endDate` | — | string |  | `2025-11-04` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `indexCode` | 指数代码 | `000300` |
| `indexName` | 指数的证券简称 | `沪深300` |
| `progFullName` | 发布机构全称 | `中证指数有限公司` |
| `exchangeCd` | 交易市场代码 | `S` |
| `date` | 行情时间 | `2025-11-06 00:00:00` |
| `indexMarketValue` | 指数的总市值 | `122081713834.268` |
| `pe` | 市盈率 | `14.3326` |
| `pb` | 市净率 | `1.376` |
| `peRank5y` | 近五年PE百分位 | `0.8399` |
| `pbRank5y` | 近五年PB百分位 | `0.6399` |
| `turnoverRate` | 换手率 | `0.0068` |
| `divYield` | 股息率 | `0.0269` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Query 可选参数: beginDate, endDate, pageNum, pageSize
investoday-api index/valuation indexCode=399300
```
