# 指数 / 特色数据

---

## 指数行业暴露

接口路径：`index/industry-exposure`
请求方式：**`POST`**
tool_id：`list_idx_idu_exposure`

接口说明：支持通过指数代码列表或行业代码列表（二选一），结合指定查询日期（格式yyyy-MM-dd），可筛选行业级别、最小行业持仓权重等条件，查询指数的行业暴露数据，包括指数及对应行业的代码与名称、行业级别、行业在指数中的持仓权重，以及数据的生效日期（格式yyyy-MM-dd HH:mm:ss）和截止日期（格式yyyy-MM-dd HH:mm:ss），可用于分析指数的行业持仓分布、行业权重占比等投研分析场景，支持分页查询。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `indexCodes` | — | array | 指数代码列表，与industryCodes组成多选一参数【与industryCodes组成多选一参数，必须且只能传递其中一个】 | `['000300', '000905']` |
| `industryCodes` | — | array | 行业代码列表，与indexCodes组成多选一参数【与indexCodes组成多选一参数，必须且只能传递其中一个】 | `['640000', '730000']` |
| `industryLevel` | — | integer | 行业级别 | `1` |
| `queryDate` | ✅ | string | 关系有效日期（格式yyyy-MM-dd） | `2026-09-01` |
| `minIndustryWeight` | — | number | 行业在指数中的最小持仓比重。 最小值:0; 最大值:100; | `10` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `startDate` | 生效日期 | `2026-08-01 00:00:00` |
| `endDate` | 截止日期 | `9999-12-31 00:00:00` |
| `indexCode` | 指数代码 | `000300` |
| `indexName` | 指数名称 | `沪深300指数` |
| `industryCode` | 行业代码 | `480000` |
| `industryName` | 行业名称 | `银行` |
| `industrySystemInt` | 行业体系数字代码 | `4` |
| `industryLevel` | 行业级别 | `1` |
| `industryWeight` | 行业在指数中的持仓比重 | `12.35` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Body JSON 可选参数: indexCodes, industryCodes, industryLevel, minIndustryWeight, pageNum, pageSize
investoday-api index/industry-exposure --method POST --body-json '{"queryDate":"2026-09-01"}'
```
