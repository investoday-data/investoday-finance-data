# 指数 / 财务数据

---

## 指数财务数据

接口路径：`index/finance`
请求方式：**`POST`**
tool_id：`list_index_finance`

接口说明：支持通过单个指数代码、批量指数代码列表，结合报告日期范围（格式yyyy-MM-dd）及分页参数，查询指数的财务数据，包含指数代码、报告年度、报告时期、报告日期（yyyy-MM-dd HH:mm:ss）、营业收入、净利润、净资产收益率、净资产收益率TTM、营业收入同比变化率、净利润同比变化率，可用于分析指数的财务表现及年度同比变动情况

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `indexCode` | — | string | 指数代码【与indexCodes组成多选一参数，必须且只能传递其中一个】 | `000300` |
| `indexCodes` | — | array | 指数代码列表【与indexCode组成多选一参数，必须且只能传递其中一个】 | `['000300', '000905']` |
| `beginDate` | — | string | 开始日期，格式yyyy-MM-dd | `2015-03-31` |
| `endDate` | — | string | 结束日期，格式yyyy-MM-dd | `2025-12-31` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `indexCode` | 指数代码 | `000300` |
| `reportYear` | 报告年度 | `2015` |
| `reportPeriod` | 报告时段 | `0103` |
| `reportDate` | 报告期日期，由报告年度和报告时段转换 | `2015-03-31 00:00:00` |
| `operatingRevenue` | 业务收入 | `125000000` |
| `netProfit` | 净利润 | `16000000` |
| `roePct` | 净资产报酬率（%） | `13.27` |
| `roeTtmPct` | 净资产报酬率 TTM（%） | `14.05` |
| `operatingRevenueYoyPct` | 业务收入同比变化率（%），与上年同期比较；对比值为空或0时返回NULL | `8.5` |
| `netProfitYoyPct` | 净利润同比变动率（%），分母取上年同期净利润绝对值；正值表示改善或亏损收窄，负值表示恶化或亏损扩大；任一值为空或上年同期为0时返回NULL | `8.5` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Body JSON 可选参数: indexCode, indexCodes, beginDate, endDate, pageNum, pageSize
investoday-api index/finance --method POST --body-json '{"indexCode":"000300","indexCodes":["000300","000905"],"beginDate":"2015-03-31"}'
```
