## 个股一致预期综合指标

接口路径：`consensus/stk-metric`
请求方式：**`POST`**
tool_id：`list_consensus_stk_metric`

接口说明：通过股票代码和发布日期范围，查询个股的卖方分析师一致预期综合指标，包括历史及未来财年的营收、净利润、每股收益、净资产、现金流、ROE、PE、PS、PB、PEG等核心财务指标的预期值、增长率、目标价、评级分数以及最新股价和总股本，用于深度财务分析和投资决策。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `stockCodes` | ✅ | array | 股票代码 | `['000001', '600519']` |
| `beginDate` | ✅ | string | 开始日期（格式yyyy-MM-dd） | `2020-01-01` |
| `endDate` | ✅ | string | 结束日期（格式yyyy-MM-dd） | `2025-03-30` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |
| `data` |  | — |

### 接口示例

```bash
# Body JSON 可选参数: pageNum, pageSize
investoday-api consensus/stk-metric --method POST --body-json '{"stockCodes":["000001","600519"],"beginDate":"2020-01-01","endDate":"2025-03-30"}'
```

## 证券投资评级

接口路径：`consensus/stk_rating`
请求方式：**`POST`**
tool_id：`list_consensus_stk_rating`

接口说明：通过指定股票代码（可批量）、报告范围类型（可选考虑补录入/仅公司报告等4种类型）、以及日期范围（格式为yyyy-MM-dd），可查询A股、B股的证券投资评级数据，包括发布日期、股票基本信息、综合评级、各类评级的机构数量、分析师情绪指数、目标价格区间及上涨空间等核心指标，支持分页查询，可用于分析机构对股票的投资态度、评估股价预期空间，辅助投资决策。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `stockCodes` | ✅ | array | 股票代码 | `['000001', '600519']` |
| `reportType` | ✅ | integer | 研报范围 | `1` |
| `beginDate` | ✅ | string | 开始日期（格式yyyy-MM-dd） | `2020-01-01` |
| `endDate` | ✅ | string | 结束日期（格式yyyy-MM-dd） | `2025-03-30` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |
| `data` |  | — |

### 接口示例

```bash
# Body JSON 可选参数: pageNum, pageSize
investoday-api consensus/stk_rating --method POST --body-json '{"stockCodes":["000001","600519"],"reportType":1,"beginDate":"2020-01-01","endDate":"2025-03-30"}'
```
