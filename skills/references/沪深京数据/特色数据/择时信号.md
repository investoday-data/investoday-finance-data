## 行情技术指标(数据挖掘)

接口路径：`stock/market-technical-indicators`
请求方式：**`POST`**
tool_id：`list_stock_market_ind_dm`

接口说明：根据股票代码和日期范围（格式为yyyy-MM-dd）查询指定沪深京股票在特定时间段内的行情技术指标数据，包括成交量与开盘价相关性、成交量与收盘价排序、开盘价收益率排序、最高价与成交量相关性排序、收盘价收益率、收盘价波动性排序、价量多重排序、最高价波动性排序、最高价与成交量排名相关性、收盘价市值中性化因子、收盘位置因子、迭代收盘相对位置因子以及市值排名迭代收益率因子等核心量化因子，用于股票量化分析和策略研究。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `stockCode` | — | string | 股票代码【与stockCodes组成多选一参数，必须且只能传递其中一个】 | `002594` |
| `stockCodes` | — | array | 股票代码列表【与stockCode组成多选一参数，必须且只能传递其中一个】 | `['000001', '600519']` |
| `beginDate` | — | string | 开始日期（格式yyyy-MM-dd）。 最小值:2020-01-01; | `2020-01-01` |
| `endDate` | — | string | 结束日期（格式yyyy-MM-dd） | `2025-01-01` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |
| `data` |  | — |

### 接口示例

```bash
# Body JSON 可选参数: stockCode, stockCodes, beginDate, endDate, pageNum, pageSize
investoday-api stock/market-technical-indicators --method POST --body-json '{"stockCode":"002594","stockCodes":["000001","600519"],"beginDate":"2020-01-01"}'
```

## 股票趋势结构筛选

接口路径：`stock/trend-structure`
请求方式：**`POST`**
tool_id：`list_stk_trend_structure`

接口说明：支持通过指定周期类型（短/中/长周期）、交易日期（格式为yyyy-MM-dd HH:mm:ss，不填则取对应周期的最新数据）、趋势信号代码（可多选，涵盖多头排列、趋势转强、突破前高、回踩均线不破、高低点结构改善、趋势阶段改善6类信号），并可搭配信号匹配模式（全匹配/任意匹配，默认全匹配）、最低趋势综合得分（取值范围0-100）及分页参数进行筛选，返回符合条件的股票代码、股票名称、交易日期、周期类型、趋势综合得分、匹配的信号代码等核心数据，适用于股票趋势分析、精准选股等投研场景。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `date` | ✅ | string | 交易日期 | `2020-01-01` |
| `cycleType` | ✅ | integer | 周期 | `1` |
| `signalCodes` | ✅ | array | 趋势信号代码 | `[1, 2, 3]` |
| `matchMode` | — | string | 多个趋势信号的匹配方式 | `2` |
| `minTrendScore` | — | string | 最低趋势综合得分，取值范围0～100；仅返回趋势得分大于或等于该值的股票 | `60` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |
| `data` |  | — |

### 接口示例

```bash
# Body JSON 可选参数: matchMode, minTrendScore, pageNum, pageSize
investoday-api stock/trend-structure --method POST --body-json '{"date":"2020-01-01","cycleType":1,"signalCodes":[1,2,3]}'
```

## 股票量价信号筛选

接口路径：`stock/volume-price`
请求方式：**`POST`**
tool_id：`list_stock_volume_price`

接口说明：支持通过指定量价分析周期（短/中/长期，必填）、交易日期（格式yyyy-MM-dd，可选，默认查询所选周期最新交易日）、最低量价综合得分、价格反馈分类（如强正向、正向等）、量价信号代码（如放量突破、缩量回调等，支持多信号全部满足或任意满足的匹配模式）及分页参数筛选股票，返回股票代码、名称、交易日期（格式yyyy-MM-dd HH:mm:ss）、周期类型、当日成交量、成交金额、换手率、5/10/20/60日平均成交量、价格反馈分类、量价综合得分及匹配的信号代码等核心数据，可用于股票量价分析、投资信号挖掘及投资决策辅助。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `date` | ✅ | string | 交易日期（格式yyyy-MM-dd），不传则查询所选周期的最新交易日期 | `2026-07-10` |
| `cycleType` | ✅ | integer | 量价分析周期：1短周期、2中周期、3长周期。 最小值:1; 最大值:3; | `2` |
| `minVolumePriceScore` | — | number | 最低量价综合得分，仅返回得分大于或等于该值的股票。 最小值:0; 最大值:100; | `60` |
| `priceFeedbacks` | — | array | 价格反馈分类列表 | `['positive', 'strong_positive']` |
| `signalCodes` | — | array | 量价信号代码列表：1放量突破、2缩量回踩、3放量滞涨、4破位确认、5换手异常。 最小值:1; 最大值:5; | `[1, 2, 5]` |
| `matchMode` | — | integer | 多个信号的匹配方式：1全部满足、2任意满足；不传默认1。 最小值:1; 最大值:2; | `1` |
| `pageNum` | — | integer | 页码，从1开始。 最小值:1; | `1` |
| `pageSize` | — | integer | 每页返回的数据条数。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |
| `data` |  | — |

### 接口示例

```bash
# Body JSON 可选参数: minVolumePriceScore, priceFeedbacks, signalCodes, matchMode, pageNum, pageSize
investoday-api stock/volume-price --method POST --body-json '{"date":"2026-07-10","cycleType":2}'
```
