接口路径：`stock/up-down-list`
请求方式：**`POST`**
tool_id：`list_stock_up_down_list`

接口说明：支持通过指定涨跌停标识（必填，1为涨停、-1为跌停、0为未涨跌停）、日期范围（格式yyyy-MM-dd）、页码和页长，查询沪深京A股、B股在指定交易日的涨跌停状态、连续涨跌停天数、昨日收盘价及昨日前复权收盘价等核心数据，可用于分析股票的极端价格行为和短期市场情绪。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `beginDate` | — | string | 开始日期（格式yyyy-MM-dd）。 最小值:2020-01-01; | `2020-01-01` |
| `endDate` | — | string | 结束日期（格式yyyy-MM-dd） | `2025-01-01` |
| `limitFlag` | ✅ | integer | 涨跌停标识 | `1` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |
| `data` |  | — |

### 接口示例

```bash
# Body JSON 可选参数: beginDate, endDate, pageNum, pageSize
investoday-api stock/up-down-list --method POST --body-json '{"limitFlag":1}'
```
