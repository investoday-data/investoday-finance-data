## 沪深京最新实时日行情

接口路径：`stock-quote/realtime`
请求方式：`GET`
tool_id：`get_stock_quote_realtime`

接口说明：获取指定沪深京股票的最新实时行情数据，包含股票当前价格、涨跌幅、开盘价、最高价、最低价、成交量、成交金额等核心数据，同时提供行业代码和行业名称信息，便于大模型进行即时的市场监测和股票分析，单次请求需指定股票代码。时间格式为yyyy-MM-dd HH:mm:ss

### 输入参数

**Query 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `stockCode` | ✅ | string | 股票代码 | `002594` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `stockCode` | 股票代码 | `002594` |
| `stockName` | 股票名称 | `比亚迪` |
| `marketType` | 市场类型(沪-sh、深-sz、京-bj) | `sz` |
| `openPrice` | 开盘价 | `359.89` |
| `closePriceYDay` | 昨日收盘价 | `361.99` |
| `currentPrice` | 当前价格 | `353.86` |
| `changeRatio` | 涨跌幅 | `-0.02245918` |
| `highPrice` | 最高价 | `359.89` |
| `lowPrice` | 最低价 | `353.62` |
| `dataTime` | 数据时间 | `2025-06-12 13:40:21` |
| `sysTime` | 系统时间 | `2025-06-12 13:40:30` |
| `status` | 状态 | `0` |
| `dealStockAmount` | 成交股数 | `100071` |
| `dealMoney` | 成交金额 | `3563408640` |
| `limitUpTime` | 涨停时间 | — |
| `limitDownTime` | 跌停时间 | — |
| `limitUpPrice` | 涨停价 | `398.19` |
| `limitDownPrice` | 跌停价 | `325.79` |
| `circulationValue` | 流通市值 | `420782222502.59` |
| `totalValue` | 总市值 | `1075403847801.6344` |
| `turnOverRate` | 换手率 | `1.8` |

### 接口示例

```bash
investoday-api stock-quote/realtime stockCode=002594
```

## 沪深京最新实时扩展日行情

接口路径：`stock-quote/realtime-ext`
请求方式：**`POST`**
tool_id：`get_stock_quote_rt_ext`

接口说明：获取沪深京股票的最新实时扩展行情数据，支持按股票代码列表查询或全市场排序筛选（如涨跌幅、涨跌停时间），返回包含最新价、开盘价、最高最低价、成交量额、多周期涨跌幅、总市值、流通市值、换手率、所属行业及涨跌停价格与时间（格式yyyy-MM-dd HH:mm:ss）等核心指标，适用于实时市场监测、异动股票发现及多维度的量化分析任务。

### 输入参数

**Query 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `order` | — | string | 排序方式(asc、desc) | `asc` |
| `sortColumn` | ✅ | string | 排序字段 | `changeRatio` |
| `page` | — | integer | 页码 | `1` |
| `pageSize` | — | integer | 页长 | `10` |

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `stockCodes` | — | array | 股票代码(单股票示例:["000001"]，多股票示例: ["600839","000002"]) | `['000001']` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `hasNextPage` | 是否有下一页 | `True` |
| `lastPage` | 上一页页码 | `1` |
| `nextPage` | 下一页页码 | `3` |
| `page` | 当前页码 | `2` |
| `pageSize` | 每页条数 | `20` |
| `pages` | 总页数 | `10` |
| `totalCount` | 总记录数 | `200` |
| `data` |  | `[{'changeRatio': 0.0, 'changeRatio1W': 0.0, 'changeRatioB10D': 0.0, 'circulationValue': 0.0, 'closePriceYDay': 0.0, 'currentPrice': 0.0, 'dataTime': '', 'dealMoney': 0.0, 'dealMoney1W': 0.0, 'dealStockAmount': 0.0, 'dealStockAmount1W': 0.0, 'highPrice': 0.0, 'industryCode': '', 'industryLV1Code': '', 'industryLV1Name': '', 'industryName': '', 'limitDownPrice': 0.0, 'limitDownTime': '', 'limitUpPrice': 0.0, 'limitUpTime': '', 'lowPrice': 0.0, 'marketType': '', 'openPrice': 0.0, 'status': '', 'stockCode': '', 'stockName': '', 'sysTime': {}, 'totalValue': 0.0, 'turnOverRate': 0.0}]` |

### 接口示例

```bash
# Query 可选参数: order, page, pageSize
# Body JSON 可选参数: stockCodes
investoday-api stock-quote/realtime-ext --method POST sortColumn=changeRatio --body-json '{"stockCodes":["000001"]}'
```
