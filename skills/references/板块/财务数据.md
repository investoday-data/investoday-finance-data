## 行业财务指标概览

接口路径：`industry/financial-overview`
请求方式：`GET`
tool_id：`get_industry_financial_overview`

接口说明：通过行业代码获取指定行业的财务指标概览数据，包含行业名称、最新季度年度、报告期、业务收入和净利润的3年平均增长率、最近四个季度的ROE、毛利率、资产负债率等核心财务指标，便于大模型进行行业财务分析和比较。

### 输入参数

**Query 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `industryCode` | ✅ | string | 申万行业代码 | `640000` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `industryCode` | 行业代码 | `640000` |
| `industryName` | 行业名称 | `能源` |
| `latestQuarterAnnual` | 最近季度年度 | `2024` |
| `latestQuarterlyRep` | 最近季度报告期 | `Q3` |
| `preQuarterQuarterlyAnnual` | 上一季度季度年度 | `2024` |
| `preQuarterRep` | 上一季度报告期 | `Q2` |
| `lastQuarterQuarterAnnual` | 次上季度季度年度 | `2024` |
| `lastQuarterReportPeriod` | 次上季度报告期 | `Q1` |
| `businessIncome3YAvgGrowthRate` | 业务收入3年平均增长率(%) | `15.5` |
| `netProfit3YAvgGrowthRate` | 净利润3年平均增长率(%) | `12.3` |
| `businessIncomeAvgGrowthRateNext3Y` | 业务收入未来3年平均增长率(%) | `18.2` |
| `netProfitAvgGrowthRate3Y` | 净利润未来3年平均增长率(%) | `14.8` |
| `latestQuarterRoe` | 最近季度净资产收益率(%) | `8.5%` |
| `latestQuarterBizIncomeGrowthRatePct` | 最近季度业务收入增长率(%) | `22.1` |
| `latestQuarterNetProfitGrowthRatePct` | 最近季度净利润增长率(%) | `19.6` |
| `preQuarterBizIncomeGrowthRate` | 上一季度业务收入增长率(%) | `18.3` |
| `preQuarterNetProfitGrowthRatePct` | 上一季度净利润增长率(%) | `16.7` |
| `preQuarterROE` | 上一季度净资产收益率(%) | `7.8` |
| `growthRateOfLastQuarterBizIncome` | 次上季度业务收入增长率(%) | `15.2` |

| `lastQuarterRoePct` | 次上季度净资产收益率(%) | `6.9%` |
| `latest4QuarterBusinessIncomeGrowthRatePct` | 最近四季度业务收入增长率(%) | `20.1` |
| `latest4QuarterNetProfitGrowthRatePct` | 最近四季度净利润增长率(%) | `17.8` |
| `latest4QuarterRoePct` | 最近四季度净资产收益率(%) | `7.8` |
| `latest4QuarterDividendPayoutRatio` | 最近四季度股息支付率(%) | `35.2` |
| `latest4QuarterDividendYield` | 最近四季度股息率 | `2.8` |

### 接口示例

```bash
investoday-api industry/financial-overview industryCode=640000
```

## 行业财务数据(ttm)

接口路径：`industry/finance-ttm`
请求方式：**`POST`**
tool_id：`list_industry_fin_ttm`

接口说明：支持通过单个行业代码或多个行业代码列表，结合报告期结束日期范围（格式yyyy-MM-dd），分页查询行业的TTM财务数据，涵盖毛利率、净利润率、资产负债率、基金持股比例、营业收入、营业利润、各类周转率、现金流净额、营收及利润增长率等多维度核心财务指标，可用于行业财务状况分析、不同行业财务对比、行业基本面研究等场景。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `industryCode` | — | string | 行业代码【与industryCodes组成多选一参数，必须且只能传递其中一个】 | `801780` |
| `industryCodes` | — | array | 行业代码列表【与industryCode组成多选一参数，必须且只能传递其中一个】 | `['801780', '801790']` |
| `beginDate` | — | string | 报告期结束日期起始值，格式yyyy-MM-dd | `2024-03-31` |
| `endDate` | — | string | 报告期结束日期终止值，格式yyyy-MM-dd | `2025-12-31` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `industryCode` | 行业代码 | `801780` |
| `industryName` | 行业名称 | `银行` |
| `reportPeriodEnd` | 报告期结束日期，格式yyyy-MM-dd | `2025-12-31` |
| `grossMarginPct` | 毛利率(%) | `28.45` |
| `netProfitMargin` | 净利润率(%) | `9.87` |
| `assetTurnoverRatio` | 资产周转率 | `0.7654` |
| `debtRatio` | 资产负债率(%) | `52.34` |
| `fundHoldingRatioPct` | 基金持股比例(%) | `3.21` |
| `fundCount` | 基金家数 | `128` |
| `operatingRevenue` | 业务收入 | `123456789` |
| `operatingProfit` | 业务利润 | `15678900` |
| `currentRatio` | 流动比率 | `1.42` |
| `quickRatio` | 速动比率 | `1.11` |
| `equityPerShare` | 每股权益 | `6.82` |
| `earningsPerShare` | 每股收益 | `0.54` |
| `returnOnEquityPct` | 净资产报酬率（权益报酬率）(%) | `10.22` |
| `returnOnAssetsPct` | 资产报酬率(%) | `4.76` |
| `inventoryTurnoverRatio` | 存货周转率 | `5.43` |
| `operatingCashFlowNet` | 经营活动产生的现金流量净额 | `23456789` |
| `operatingCashToCurrentLiabilitiesRatio` | 经营性现金与流动负债比率 | `0.32` |
| `accountsReceivableTurnoverRatio` | 应收账款周转率 | `8.54` |
| `monetaryFundsToTotalAssetsRatio` | 货币资金占总资产比例 | `0.18` |
| `receivablesToTotalAssetsRatio` | 应收账款占总资产比例 | `0.12` |
| `inventoryToTotalAssetsRatio` | 存货占总资产比例 | `0.09` |
| `intangibleAssetsToTotalAssetsRatio` | 无形资产占总资产比例 | `0.03` |
| `goodwillToTotalAssetsRatio` | 商誉占总资产比例 | `0.05` |
| `netProfit` | 净利润 | `11223344` |
| `investingCashFlowNet` | 投资活动产生的现金流量净额 | `-3456789` |
| `financingCashFlowNet` | 筹资活动产生的现金流量净额 | `4567890` |
| `recurringBusinessNetProfit` | 经常性业务产生的净利润 | `10223344` |

### 接口示例

```bash
# Body JSON 可选参数: industryCode, industryCodes, beginDate, endDate, pageNum, pageSize
investoday-api industry/finance-ttm --method POST --body-json '{"industryCode":"801780","industryCodes":["801780","801790"],"beginDate":"2024-03-31"}'
```

## 财务指标（偿债能力）

tool_id：`list__idu_fin_ind_sol_avg`

接口说明：行业财务平均指标（偿债能力）

_无参数_
