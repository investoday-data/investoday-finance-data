## 行业轮动因子

接口路径：`industry/rotation`
请求方式：`GET`
tool_id：`list_industry_rotation`

接口说明：通过行业代码和日期范围查询特定行业的轮动因子数据，包括市场情绪计温度和高低价风格相关性X动量等指标，用于分析行业轮动和市场风格变化。入参包括行业代码、开始日期（格式yyyy-MM-dd）、结束日期（格式yyyy-MM-dd）、页码和页大小；出参包括行业代码、行业名称、发布日期（格式yyyy-MM-dd HH:mm:ss）、市场情绪计温度和高低价风格相关性X动量。

### 输入参数

**Query 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `industryCode` | ✅ | string | 行业代码 | `002594` |
| `beginDate` | — | string | 开始日期（格式yyyy-MM-dd）。 最小值:2020-01-01; | `2020-01-01` |
| `endDate` | — | string | 结束日期（格式yyyy-MM-dd） | `2025-01-01` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `industryCode` | 行业代码 | `801010` |
| `industryName` | 行业名称 | `申万农林牧渔` |
| `date` | 发布日期 | `2000-01-17 00:00:00` |
| `marketSentiment` | 市场温度计温度 | `0.93333333` |
| `hlStyleCorrXMomentum` | 高低价风格相关性X动量 | `0.85` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Query 可选参数: beginDate, endDate, pageNum, pageSize
investoday-api industry/rotation industryCode=002594
```

## 行业与ETF映射

接口路径：`industry/etf-mapping`
请求方式：**`POST`**
tool_id：`list_industry_etf_mapping`

接口说明：支持通过行业代码列表、基金代码列表、年报持仓最小占比进行多条件筛选，分页查询行业与ETF的双向映射关系数据，包含发布日期、报告截止日期、行业代码、名称、级别，以及ETF的内部编码、交易代码、名称、规模，还有最新报告、季报、年报中该行业占ETF总资产、净资产的比例，以及穿透后的净资产占比，可用于构建行业与ETF的关联关系、分析ETF的行业持仓结构、筛选符合持仓占比要求的ETF等投研场景

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `industryCodes` | — | array | 行业代码列表（通过行业列表获取）【与fundCodes组成多选一参数，必须且只能传递其中一个】 | `['640000', '730000']` |
| `fundCodes` | — | array | 基金代码列表（通过基金基本信息获取）【与industryCodes组成多选一参数，必须且只能传递其中一个】 | `['512720', '515880']` |
| `minAnnualWeight` | — | number | 年报占基金总资产的最小持仓比重。 最小值:0; 最大值:100; | `20` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `publishDate` | 发布日期 | `2026-09-01 00:00:00` |
| `endDate` | 报告截止日期 | `2026-06-30 00:00:00` |
| `industryCode` | 行业代码 | `640000` |
| `industryName` | 行业名称 | `计算机` |
| `industryLevel` | 行业级别 | `1` |
| `fundId` | 今日投资内部编码 | `000001JK` |
| `fundCode` | 基金代码 | `512720` |
| `fundName` | 基金名称 | `计算机ETF` |
| `fundScale` | 基金规模 | `35.2` |
| `holdingAssetLatest` | 最新报告占基金总资产比重 | `35.2` |
| `holdingAssetQuarterly` | 季报占基金总资产比重 | `33.8` |
| `holdingAssetAnnual` | 年报占基金总资产比重 | `32.6` |
| `holdingNavLatest` | 最新报告占基金净资产比重 | `36.1` |
| `holdingNavQuarterly` | 季报占基金净资产比重 | `34.5` |
| `holdingNavAnnual` | 年报占基金净资产比重 | `33.2` |
| `holdingNavLookthrough` | 穿透后占基金净资产比重 | `37` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Body JSON 可选参数: industryCodes, fundCodes, minAnnualWeight, pageNum, pageSize
investoday-api industry/etf-mapping --method POST --body-json '{"industryCodes":["640000","730000"],"fundCodes":["512720","515880"],"minAnnualWeight":20}'
```

## 概念与ETF映射

接口路径：`concept/etf-mapping`
请求方式：**`POST`**
tool_id：`list_concept_etf_mapping`

接口说明：支持通过概念代码列表、ETF代码列表，或设置年报/半年报概念持仓比例下限进行筛选，分页查询概念与ETF的双向映射关系数据，包含概念的代码、类别、名称，ETF的代码、名称、规模，以及最新报告、季报、年报中该概念在对应ETF中的持仓比例，还有报告发布日期、最新报告截止日期、年报/半年报截止日期等信息，可用于分析概念与ETF的关联度、ETF跟踪标的情况等投研场景。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `conceptCodes` | — | array | 概念代码列表（通过概念列表获取）【与fundCodes组成多选一参数，必须且只能传递其中一个】 | `['CLS80006', 'CLS80003']` |
| `fundCodes` | — | array | 基金代码列表【与conceptCodes组成多选一参数，必须且只能传递其中一个】 | `['512480', '515880']` |
| `minAnnualWeight` | — | number | 年报或半年报概念持仓比例下限。 最小值:0; 最大值:100; | `20` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |

| `publishDate` | 发布日期 | `2026-09-01 00:00:00` |
| `endDate` | 最新报告截止日期 | `2026-06-30 00:00:00` |
| `annualEndDate` | 年报或半年报截止日期 | `2025-12-31 00:00:00` |
| `conceptCode` | 概念代码 | `CLS80006` |
| `conceptCategory` | 概念类别 | `C01` |
| `conceptName` | 概念名称 | `人工智能` |
| `fundId` | 今日投资内部编码 | `000001JK` |

| `holdingWeightQuarterly` | 季报概念持仓比例 | `34.8` |
| `holdingWeightAnnual` | 年报或半年报概念持仓比例 | `33.5` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash

investoday-api concept/etf-mapping --method POST --body-json '{"conceptCodes":["CLS80006","CLS80003"],"fundCodes":["512480","515880"],"minAnnualWeight":20}'
```

## 行业概念映射

接口路径：`industry/concept-mappings`
请求方式：**`POST`**
tool_id：`list_idu_concept_mappings`

接口说明：支持通过行业代码列表、概念代码列表、行业级别、发布日期范围（格式yyyy-MM-dd）、总市值占比最小值等多条件组合筛选，查询行业与概念的双向映射关联数据，包括发布日期（格式yyyy-MM-dd HH:mm:ss）、行业代码、行业体系、行业名称、行业级别、概念代码、概念名称、概念基于行业总市值的占比、概念基于行业流通市值的占比，可用于构建行业概念关联体系、投研中的行业概念权重分析等场景，支持分页查询。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `industryCodes` | — | array | 行业代码列表【与conceptCodes组成多选一参数，必须且只能传递其中一个】 | `['640000', '730000']` |
| `conceptCodes` | — | array | 概念代码列表【与industryCodes组成多选一参数，必须且只能传递其中一个】 | `['CLS80006', 'CLS80003']` |
| `industryLevel` | — | integer | 行业级别 | `1` |
| `beginDate` | — | string | 开始发布日期（格式yyyy-MM-dd） | `2026-01-01` |
| `endDate` | — | string | 结束发布日期（格式yyyy-MM-dd） | `2026-09-01` |
| `minTotalCapWeight` | — | number | 概念基于行业总市值的占比 | `0.2` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `date` | 发布日期 | `2026-09-01 00:00:00` |
| `industryCode` | 行业代码 | `730000` |
| `industryType` | 行业体系 | `INDUS4_CL` |
| `industryName` | 行业名称 | `通信` |
| `industryLevel` | 行业级别 | `1` |
| `conceptCode` | 概念代码 | `CLS80006` |
| `conceptName` | 概念名称 | `人工智能` |
| `weightTotalCap` | 概念基于行业总市值的占比 | `0.35` |
| `weightFreeFloatCap` | 概念基于行业流通市值的占比 | `0.32` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Body JSON 可选参数: industryCodes, conceptCodes, industryLevel, beginDate, endDate, minTotalCapWeight, pageNum, pageSize
investoday-api industry/concept-mappings --method POST --body-json '{"industryCodes":["640000","730000"],"conceptCodes":["CLS80006","CLS80003"],"industryLevel":1}'
```
