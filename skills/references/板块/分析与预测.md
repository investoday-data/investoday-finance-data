## 行业景气度

接口路径：`industry/prosperity-index`
请求方式：`GET`
tool_id：`list_industry_prosperity_index`

接口说明：通过行业代码查询行业景气度数据，包括ROE(TTM)环比增速、毛利率(TTM)环比增速、净利率(TTM)环比增速等关键财务指标及其标签，适用于行业分析和投资决策。

### 输入参数

**Query 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `industryCode` | ✅ | string | 行业代码 | `740000` |
| `beginDate` | — | string | 开始日期（格式yyyy-MM-dd）。 最小值:2020-01-01; | `2025-01-01` |
| `endDate` | — | string | 结束日期（格式yyyy-MM-dd） | `2025-01-01` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `industryCode` | 行业代码 | — |
| `industryName` | 行业名称 | — |
| `reportYear` | 报告年度 | — |
| `reportPeriod` | 报告时段 | — |
| `roeTtmQoqGrowth` | ROE(TTM)环比增速 | — |
| `roeTtmQoqGrowthLabel` | ROE(TTM)环比增速的标签 | — |
| `grossMarginTTMMoMGrowth` | 毛利率(TTM)环比增速 | — |
| `grossMarginTTMMoMGrowthLabel` | 毛利率(TTM)环比增速的标签 | — |
| `ttmNetProfitMarginQoq` | 净利率(TTM)环比增速 | — |
| `ttmNetProfitMarginQoqLabel` | 净利率(TTM)环比增速的标签 | — |
| `latestQtrNetProfitYoyQoq` | 最近一季度归母净利润同比增速的环比增速 | — |
| `latestQtrNetProfitYoyQoqLabel` | 最近一季度归母净利润同比增速的环比增速的标签 | — |
| `latestQtrOpIncomeYoyQoq` | 最近一季度营业总收入同比增速的环比增速 | — |
| `latestQtrOpIncomeYoyQoqLabel` | 最近一季度营业总收入同比增速的环比增速的标签 | — |
| `latestQtrAdjNetProfitYoyMom` | 最近一季度扣非净利润同比增速的环比增速 | — |
| `latestQtrAdjNetProfitYoyMomLabel` | 最近一季度扣非净利润同比增速的环比增速的标签 | — |
| `totalTag` | 总的标签 | — |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Query 可选参数: beginDate, endDate, pageNum, pageSize
investoday-api industry/prosperity-index industryCode=740000
```

## 分析师行业景气度

接口路径：`industry/prosperity-index`
请求方式：**`POST`**
tool_id：`list_industry_pros_idx`

接口说明：通过必填的申万行业代码，可结合发布日期范围（格式yyyy-MM-dd）、分页参数，查询申万行业体系下的分析师行业景气度数据，包含行业代码、行业名称、发布日期、行业体系信息，以及净利润、每股收益、净资产收益率、营业收入的T+1、T+2调整率及方向标签，还有同比增速、3年复合增长率的调整率及方向标签，以及景气度指标，可用于行业盈利预测跟踪、景气度分析等投研场景。

### 输入参数

**Query 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `industryCode` | ✅ | string | 申万行业代码 | `740000` |
| `beginDate` | — | string | 开始发布日期，格式yyyy-MM-dd。 最小值:2020-01-01; | `2025-01-01` |
| `endDate` | — | string | 结束发布日期，格式yyyy-MM-dd | `2026-08-18` |

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `industryCode` | 行业代码 | `740000` |
| `industryName` | 行业名称 | `计算机` |
| `publishDate` | 发布日期 | `2026-08-18 00:00:00` |
| `industrySystem` | 行业体系 | `4` |
| `netProfitT1Mom` | 一致预测净利润(T+1)相对上月修正率，0.0250表示上调2.5% | `0.025` |
| `netProfitT1MomTag` | 一致预测净利润(T+1)月度修正标签：上调至少1%为1，下调至少1%为-1，其他为0 | `1` |
| `epsT1Mom` | 一致预测每股收益(T+1)相对上月修正率 | `0.018` |
| `epsT1MomTag` | 一致预测每股收益(T+1)月度修正标签 | `1` |
| `roeT1Mom` | 一致预测ROE(T+1)相对上月修正率 | `0.012` |
| `roeT1MomTag` | 一致预测ROE(T+1)月度修正标签 | `1` |
| `revenueT1Mom` | 一致预测营业收入(T+1)相对上月修正率 | `0.016` |
| `revenueT1MomTag` | 一致预测营业收入(T+1)月度修正标签 | `1` |
| `netProfitT2Mom` | 一致预测净利润(T+2)相对上月修正率 | `0.021` |
| `netProfitT2MomTag` | 一致预测净利润(T+2)月度修正标签 | `1` |
| `epsT2Mom` | 一致预测每股收益(T+2)相对上月修正率 | `0.017` |
| `epsT2MomTag` | 一致预测每股收益(T+2)月度修正标签 | `1` |
| `roeT2Mom` | 一致预测ROE(T+2)相对上月修正率 | `0.011` |
| `roeT2MomTag` | 一致预测ROE(T+2)月度修正标签 | `1` |
| `revenueT2Mom` | 一致预测营业收入(T+2)相对上月修正率 | `0.014` |
| `revenueT2MomTag` | 一致预测营业收入(T+2)月度修正标签 | `1` |
| `netProfitYoyMom` | 一致预测净利润同比增速相对上月的修正率 | `0.03` |
| `netProfitYoyMomTag` | 一致预测净利润同比增速月度修正标签 | `1` |
| `roeYoyMom` | 一致预测ROE同比增速相对上月的修正率 | `-0.012` |
| `roeYoyMomTag` | 一致预测ROE同比增速月度修正标签 | `-1` |
| `revenueYoyMom` | 一致预测营业收入同比增速相对上月的修正率 | `0.019` |
| `revenueYoyMomTag` | 一致预测营业收入同比增速月度修正标签 | `1` |
| `netProfitCagr3yMom` | 一致预测净利润未来3年CAGR相对上月的修正率 | `0.022` |
| `netProfitCagr3yMomTag` | 一致预测净利润未来3年CAGR月度修正标签 | `1` |
| `revenueCagr3yMom` | 一致预测营业收入未来3年CAGR相对上月的修正率 | `0.015` |
| `revenueCagr3yMomTag` | 一致预测营业收入未来3年CAGR月度修正标签 | `1` |

### 接口示例

```bash
# Query 可选参数: beginDate, endDate
# Body JSON 可选参数: pageNum, pageSize
investoday-api industry/prosperity-index --method POST industryCode=740000 --body-json '{"pageNum":1,"pageSize":10}'
```
