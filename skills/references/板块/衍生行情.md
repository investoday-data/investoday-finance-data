## 行业及关联成分股的最新实时日行情

接口路径：`industry-quote/stock-realtime`
请求方式：`GET`
tool_id：`get_industry_stock_realtime_quote`

接口说明：通过行业代码（必填）查询对应行业及相关成分股的最新实时日行情数据，支持按响应字段指定排序规则、分页查询，返回行业整体行情信息（含价格、涨跌幅、成交量、近一周涨跌幅、总市值、行业内涨跌排名、涨跌家数统计、领涨股信息等）、成分股实时行情详情（含股票代码、名称、最新价、涨跌幅、开盘价、最高价、最低价等）及分页相关数据，可用于行业行情监测、成分股分析、市场热点追踪等场景。

### 输入参数

**Query 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `industryCode` | ✅ | string | 行业代码 | `740000` |
| `sortColumn` | — | string | 排序字段（响应字段） | `changeRatio` |
| `order` | — | string | 排序方向 | `desc` |
| `page` | — | integer | 页码 | `1` |
| `pageSize` | — | integer | 页长 | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `data` |  | `[]` |
| `totalCount` | 总记录数 | `33` |
| `pages` | 总页数 | `4` |
| `page` | 当前页码 | `4` |
| `pageSize` | 每页条数 | `10` |
| `hasNextPage` | 是否有下一页 | `True` |
| `nextPage` | 下一页页码 | `2` |
| `lastPage` | 是否最后一页 | `False` |

### 接口示例

```bash
# Query 可选参数: sortColumn, order, page, pageSize
investoday-api industry-quote/stock-realtime industryCode=740000
```

| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

| `pageNum` | — | integer | 页码。 最小值:1; | `1` |

| 字段名 | 说明 | 示例 |
