## 股票缠论K线

接口路径：`stock/chan-kline`
请求方式：**`POST`**
tool_id：`list_stock_chan_kline`

接口说明：支持通过单个股票代码或批量股票代码数组，查询对应A股、B股的缠论K线相关数据，包括股票代码、名称、交易日期（格式为yyyy-MM-dd HH:mm:ss）、计算状态，以及一买、二买、三买和一卖、二卖、三卖参考价格，可用于缠论框架下的股票交易分析与决策参考。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `stockCodes` | — | array | 股票代码列表【与stockCode组成多选一参数，必须且只能传递其中一个】 | `['000001', '600519']` |
| `stockCode` | — | string | 股票代码【与stockCodes组成多选一参数，必须且只能传递其中一个】 | `000001` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `stockCode` | 股票代码 | `000001` |
| `stockName` | 股票名称 | `平安银行` |
| `tradeDate` | 交易日期 | `2026-08-06 00:00:00` |
| `calcStatus` | 计算状态 | — |
| `firstBuyPrice` | 一买参考价 | `10.25` |
| `secondBuyPrice` | 二买参考价 | `10.12` |
| `thirdBuyPrice` | 三买参考价 | `10.36` |
| `firstSellPrice` | 一卖参考价 | `11.25` |
| `secondSellPrice` | 二卖参考价 | `11.48` |
| `thirdSellPrice` | 三卖参考价 | `11.8` |

### 接口示例

```bash
# Body JSON 可选参数: stockCodes, stockCode
investoday-api stock/chan-kline --method POST --body-json '{"stockCodes":["000001","600519"],"stockCode":"000001"}'
```
