# 因子库 / 股票

---

## 股票估值因子

接口路径：`stock/valuation-factors`
请求方式：**`POST`**
tool_id：`list_stock_val_factors`

接口说明：支持通过股票代码列表及时间范围查询股票估值因子数据，返回包括股票名称、代码、市场代码、发布日期的EV/Sales、EV/EBITDA、PEG（未来1年/3年、过去1年/3年）、市盈率PE（最新年报/最近12个月/周期调整）、股息率、市销率PS、价格现金流比PCF、股价自由现金流比P/FCF、市净率PB及总市值/总负债等核心估值指标。

### 输入参数

**Query 参数**

_无参数_

**Body JSON 参数**

| 参数名 | 必填 | 类型 | 说明 | 示例 |
|--------|:----:|------|------|------|
| `stockCodes` | — | array | 股票代码列表 | `['000001', '600519']` |
| `beginDate` | — | string | 开始日期（格式yyyy-MM-dd） | `2026-07-01` |
| `endDate` | — | string | 结束日期（格式yyyy-MM-dd） | `2026-07-31` |
| `pageNum` | — | integer | 页码。 最小值:1; | `1` |
| `pageSize` | — | integer | 页长。 最小值:1; 最大值:500; | `10` |

### 输出参数

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `stockName` | 股票名称 | `贵州茅台` |

| `stockCode` | 股票代码 | `600519` |
| `marketCode` | 市场代码 | `S` |
| `evSales` | 企业价值/销售额（EV/Sales） | `12.3456` |
| `evEbitda` | 企业价值/EBITDA | `10.2345` |
| `evEbit` | 企业价值/EBIT | `11.2345` |
| `evFcf` | 企业价值/自由现金流 | `15.6789` |
| `pegF1y` | 未来1年PEG | `1.2345` |
| `pegF3y` | 未来3年PEG | `1.4567` |
| `peg1y` | 过去1年PEG | `1.1234` |
| `peg3y` | 过去3年PEG | `1.3456` |
| `peEbitdaCagr3y` | 市盈增长比 | `0.8765` |
| `peMry` | 市盈率PE（最新年报） | `18.4567` |
| `peTtm` | 市盈率PE（最近12个月） | `20.1234` |
| `peCape` | 周期调整市盈率 | `22.3456` |

| `psTtm` | 市销率（最近12个月） | `3.2345` |
| `pcfTtm` | 价格/现金流（最近12个月） | `8.3456` |
| `pFcf` | 股价/自由现金流 | `14.5678` |
| `pb` | 市净率PB | `2.3456` |
| `mveToTl` | 总市值/负债合计 | `1.8765` |
| `pageNum` | page number | `1` |
| `pageSize` | page size | `100` |
| `totalCount` | total count | `0` |

### 接口示例

```bash
# Body JSON 可选参数: stockCodes, beginDate, endDate, pageNum, pageSize
investoday-api stock/valuation-factors --method POST --body-json '{"stockCodes":["000001","600519"],"beginDate":"2026-07-01","endDate":"2026-07-31"}'
```
